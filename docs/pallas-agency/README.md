# Pallas Agency — Guia Estrutural do Projeto

Este diretório concentra os documentos de referência para guiar a construção do web app/landing page da Pallas Agency.

## Objetivo

Construir uma landing page de alta autoridade para posicionar a Pallas Agency como uma consultoria Engineer-First de MarTech, Marketing Measurement e Aquisição.

A página deve comunicar que a empresa não atua como uma agência de mídia tradicional, mas como uma operação de tecnologia, ciência aplicada e engenharia de crescimento.

## Documentos

- `01-identidade-e-posicionamento.md`: identidade, tom de voz, paleta e referências.
- `02-estrutura-da-landing-page.md`: seções da landing page, copy base e intenção de cada bloco.
- `03-metodologia-e-ofertas.md`: metodologia Closed-Loop, squad e modelos de engajamento.
- `04-diretrizes-tecnicas.md`: requisitos técnicos, performance, tracking, SEO e mobile.
- `05-backlog-inicial.md`: tarefas iniciais sugeridas para transformar o briefing em implementação.

## Princípio criativo

A Pallas Agency deve parecer uma empresa de tecnologia aplicada ao crescimento: minimalista, precisa, sofisticada e orientada a ROI.
